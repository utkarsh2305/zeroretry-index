# ZeroRetry Index

ZeroRetry Index is a Chrome extension that helps you **navigate, review, and reuse long AI conversations**.

It adds a draggable sidebar to ChatGPT that lets you:
- See a conversation index (table of contents)
- Mark important sections for later review
- Search within the current conversation
- Export a structured outline to Markdown

This product is part of the **ZeroRetry** brand.

---

## What problem does it solve?

Long AI conversations quickly become hard to manage:
- You lose track of earlier questions and answers
- Scrolling is slow and error-prone
- Important insights get buried
- You end up re-asking questions you already solved

ZeroRetry Index solves this by giving structure, navigation, and recall to long AI chats — without using AI itself.

## Scope (MVP)

**In scope**
- ChatGPT web support
- Conversation index from user messages
- Important / starred sections
- Search within the current conversation
- Export outline to Markdown
- Draggable sidebar
- Local-only storage (no backend, no AI)

**Out of scope**
- AI summaries or inference
- Cross-conversation search
- Cloud sync or accounts
- Claude / Gemini / Perplexity support (planned later)
